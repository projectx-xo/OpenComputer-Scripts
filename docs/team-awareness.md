# BaseCenter integration removed

STRATCOM 3.14.0 removes BaseCenter equipment identity polling, team labels, the `team`/`assets` commands and BaseCenter proximity warnings. Old saved team preferences are ignored. Update CENTRAL and nodes with `upgrade`.

Authentication keys and network IDs, satellite communications, radar/IFF and explicit launch confirmations remain supported. A network ID such as BLUE identifies the authenticated network; it does not require a BaseCenter team.
